# Checklist para liberar um escritório na beta

## Antes da instalação

- confirmar que o escritório possui computador Windows atualizado;
- definir responsável pelo CheckFiscal;
- explicar que a versão é local e assistida;
- informar que o escopo atual vai até 12/2026;
- alinhar que os resultados são estimativas conservadoras;
- obter concordância sobre tratamento e guarda dos documentos fiscais.

## Na instalação

- conferir a versão 1.42 e a porta 8142;
- cadastrar uma empresa de teste;
- importar uma malha conhecida;
- se houver Tipo 17, confirmar que os PGDAS foram planejados; se a etapa mostrar “Falha no planejamento”, não avançar para análise;
- se aparecer “Não se aplica”, conferir se o PDF original realmente não contém Tipo 17;
- confirmar o bloqueio de identidade em empresa errada;
- importar os PGDAS;
- gerar uma estimativa completa;
- abrir o relatório;
- gerar e guardar o primeiro backup;
- registrar onde os dados locais estão armazenados.

## Operação

- backup semanal, no mínimo;
- backup antes de atualização de versão;
- não enviar o pacote de backup por canais inseguros;
- usar o pacote de diagnóstico no suporte, não o banco completo;
- conferir o cálculo com documentos oficiais antes de qualquer retificação.
