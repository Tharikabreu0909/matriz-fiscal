# Conclusão do estudo contábil v1

## Princípio

O valor apontado pela malha mede a exposição, mas não substitui a análise
contábil dos documentos.

## Dados registrados

- competência;
- valor validado do SPED/LFE;
- valor validado do PGDAS;
- motivo;
- observação;
- data de criação e atualização.

## Cenários

### CONSERVATIVE_FISCAL_EXPOSURE

Mantém o valor considerado pelo Fisco.

### VALIDATED_REGULARIZATION

Usa o valor concluído pela contabilidade.

## Auditoria

A conclusão não altera nem apaga:

- malha original;
- PGDAS importado;
- cenário conservador;
- memória de cálculo da exposição.

Cada novo recálculo é armazenado separadamente pelo cenário.
