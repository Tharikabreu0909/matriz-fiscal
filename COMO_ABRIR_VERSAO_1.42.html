Matriz Fiscal versão 1.42

Correção da instalação: esta versão evita a dependência extra que estava tentando compilar PyYAML e seleciona Python 3.11, 3.12 ou 3.13.

Como abrir no Windows

1. Extraia o ZIP em uma pasta nova. Não execute o arquivo diretamente de dentro do ZIP.
2. Execute INICIAR_CHECKFISCAL_WINDOWS.bat.
3. O sistema abre em http://127.0.0.1:8142. Confirme que o painel mostra VERSÃO 1.42.

Se o instalador informar que só encontrou Python 3.15

Instale Python 3.13 de 64 bits pelo site oficial do Python. Durante a instalação, marque Add Python to PATH. Você pode manter o Python 3.15 instalado; os dois podem coexistir. Depois, execute o BAT novamente.

Se a instalação anterior falhou

A versão 1.42 recria automaticamente apenas a pasta temporária .venv se ela tiver sido criada com uma versão incompatível do Python.
Não apague a pasta %LOCALAPPDATA%\CheckFiscal: ela contém o banco de dados local.
